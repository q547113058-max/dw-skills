## ECC Migration Policy

ECC modules are selectively migrated as workflow rules and activation policies. Runtime files such as commands, hooks, agents, scripts, platform configs, and MCP configs are not copied by default.

See `docs/12-ecc-selective-migration-policy.md` and `docs/ecc-module-migration-review.md`.
