# DW 分级执行清单

本清单仅在任务需要清单时读取。只执行当前级别和已命中的门禁，不逐项证明无关内容为 N/A。

## Quick

- [ ] 范围明确、低风险、易回滚。
- [ ] 只读取触达文件和命中的项目规则。
- [ ] 运行最接近改动的验证并审查 diff。

## Standard

- [ ] 明确行为影响、最低通过条件、质量目标、失败边界和验收证据；需求已清楚时不重复确认。
- [ ] 复杂任务只维护一个包含目标、步骤、风险和阶段检查点的计划。
- [ ] 运行项目已有且相关的 formatter、lint、type check、tests 或 build。
- [ ] 对命中的输入、数据、文件、配置或外部边界做轻量检查。
- [ ] 不制造额外计划、审查、评分或日志产物。

## High-Risk

- [ ] 写明具体高风险来源，不以技术名词代替风险判断。
- [ ] 验证相关权限、失败路径、兼容性和回滚条件。
- [ ] 只增加命中风险所需的专项审查和集成/E2E 验证。
- [ ] 发布、交接或用户要求时输出完整风险与验证摘要。

## 外部操作

- [ ] 只读查询可直接执行并报告来源。
- [ ] mutation 必须有明确授权或仓库既有交付策略。
- [ ] force-push、历史改写、生产发布、删除和设置变更单独确认。

## 恢复记录

仅跨会话、中断风险、复杂失败、交接或稳定决策需要恢复记录。任务等级本身不触发日志或检查点。

## 显式扩展

- [ ] 直接阅读不足时才使用代码图谱；长期架构图谱才使用 Graphify。
- [ ] 用户明确要求并行且环境支持时才启用多 Agent。
- [ ] 实际使用、安装、更新或迁移 Skill 时才读取更新策略。
