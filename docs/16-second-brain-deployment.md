# 第二大脑部署与迁移

本文件只在第二大脑迁移、恢复或跨环境同步任务中读取。普通开发任务不加载这些部署细节。

## 当前权威范围

- 云盘迁移前，仅 `CODEX_HOME=D:\Codex\home` 可以启用第二大脑。
- `D:\Codex\vault` 是唯一权威 Vault。
- 其他电脑、Codex Home 和 Agent 环境不得复制或启用路由，不得初始化、读取或更新平行项目记忆。
- `dw-skills` 只维护一个物理 checkout；活动路径可以使用目录联接。

## 扩展启用门禁

扩大到其他环境前必须明确验证：

1. 双向同步和离线恢复。
2. 同时编辑时的冲突副本处理。
3. 跨设备项目键和路径映射一致。
4. secrets、凭据、私人原文和可由 Git 重建内容不会进入 Vault。
5. 回滚到单一权威 Vault 的步骤可执行。

任何一项未验证时，其他环境继续保持关闭。迁移或恢复过程需要会话记录时，配合 `docs/10-session-checkpoints-and-recovery.md` 使用。
