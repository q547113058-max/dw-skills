# Code Structure Analysis

This is a conditional reference, not a default step.

- Read the directly relevant source, tests, and project documentation first.
- Use a relationship tool only when imports, calls, dependencies, or boundaries cannot be established by direct reading.
- Use a long-term architecture or cross-document graph only when the task genuinely needs it and an appropriate tool is available.
- Cross-check tool output against source and tests; a graph is evidence, not a correctness proof.
- Do not create a graph for ordinary file reading or lightweight local changes.
