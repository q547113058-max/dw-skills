# 开发日志标准

每天使用一个日志文件：

```text
dev-logs/YYYY-MM-DD.md
```

## 规则

1. 会话开始时，如果当天日志不存在就创建。
2. 会话结束前更新日志。
3. 在 `会话` 中写明当前任务。
4. 在 `已完成` 中记录完成事项。
5. 在 `变更文件` 中记录文件路径。
6. 在 `决策` 中记录重要选择和原因。
7. 在 `验证` 中记录运行的检查和结果。
8. 在 `未解决问题` 中记录阻塞项。
9. 在 `下一步待办` 中记录后续动作。
